# Importing existing material: design brief

Raised by Tim 2026-10-30. To discuss; nothing is decided.

## The idea

With an AI chosen, a writer can point Fletchery at existing material: a folder on the computer, a Google Drive folder, or premade files. The AI reads it and assembles a draft story bible from it. Tim's example: a body of existing notes and drafts for EOL that he'd like Fletchery to analyze and sort into sections.

## Questions to discuss

- **Sources:** a local folder, Google Drive, single files, or pasted text. Which file types come first (Markdown, plain text, Word, Google Docs, PDF, images)?
- **Where the AI fits:** the Claude Code bridge, which can already read local files, or an API key. Which edition handles Google Drive?
- **What comes out:** AI-drafted entries marked `author: ai-draft` for the writer to review and mark canon, never overwriting text the writer wrote. How are conflicts with existing entries shown?
- **Scale:** large collections may need batching, a progress view, and a way to stop and resume.
- **Traceability:** whether each drafted fact links back to the source file it came from.
- **The originals:** source material is read, never moved or changed.
